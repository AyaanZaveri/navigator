# Rectangular language and country flags

Locally vendored SVGs from [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons), version **1.6.20**, with the upstream MIT license. The [GitHub mirror](https://github.com/purecatamphetamine/country-flag-icons) belongs to the same author.

Country artwork uses the upstream 3:2 aspect ratio. `language/` contains copies of the representative country artwork listed in `lib/media/track-flags.ts`; English uses GB, consistent with the previous English marker. An explicit locale region takes priority. Flags are decorative: the language name and code remain authoritative. Languages without a representative asset use the existing generic language icon.

Source archive: https://registry.npmjs.org/country-flag-icons/-/country-flag-icons-1.6.20.tgz
