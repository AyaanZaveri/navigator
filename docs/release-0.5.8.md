# Navigator 0.5.8

Navigator 0.5.8 supports Windows and macOS. This update improves add-on setup, keyboard navigation, and theme consistency.

### New features and improvements

- **Easier add-on setup:** Install an add-on from its link, preview its details, or open the add-on directory. Mobile screens use a drawer with actions that fit the available space.
- **Clearer keyboard navigation:** Shared controls use consistent focus indicators. Media cards have one details link before Play, and vertical arrow keys can leave horizontal segmented controls.
- **Theme-aware update notes:** Release notes use readable text and background colors in light and dark system themes on Windows and macOS.
- **Consistent page backgrounds:** Safari keeps the page background behind the navbar. Settings and Add-ons use softer gradients, and Settings fields adapt to the available width.
- **Interface polish:** Sign-in controls, buttons, dialogs, and add-on labels have more consistent spacing. Avatar menu icons use a gentler hover transition.

### Windows installation

Requires **Windows 11 on an x64 PC**.

Download and run the installer. Installed versions with in-app update support can update through Navigator. Portable ZIP copies require manual updates.

The installer does not have a Windows publisher signature. In-app updates use cryptographic signatures to verify downloads.

### macOS installation

Requires **Apple Silicon and macOS 13.5 or later**.

Extract the app ZIP and move Navigator to Applications. Navigator 0.5.3 and later can update in the app. Versions through 0.5.2 require a manual upgrade to enable in-app updates.

This build uses an ad hoc signature and is not notarized by Apple. macOS may require approval before you can open it. In-app updates use cryptographic signatures to verify downloads.
